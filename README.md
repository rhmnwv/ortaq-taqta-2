# Ортақ тақта

«Ортақ тақта» — қолжетімді сабақтар кітапханасының қазақша хакатон MVP-нұсқасы. Бір дайын математика сабағын мұғалім кабинетінен интерактивті тақта мен оқушының құрылғысына жіберуге болады.

- [Онлайн демо](https://ortaq-taqta-demo.zhandos.chatgpt.site) бір браузердің үш қойындысында жұмыс істейді. Оның коды `web-demo/` бумасында.
- [Хакатон презентациясы](docs/Ortaq-taqta.pptx) жобаның мәселесін, шешімін және пилот жоспарын сипаттайды.
- Жергілікті сынып нұсқасы бір Wi-Fi желісіндегі бөлек құрылғыларды қолдайды.

## Іске қосу

Репозиторийдің түбіріндегі PowerShell терезесінде Node.js арқылы серверді бастаңыз.

```powershell
node .\server.mjs
```

1. Бір компьютерде сынау үшін http://localhost:8080 мекенжайын үш қойындыда ашыңыз.
2. Планшет пен тақта үшін компьютерді және құрылғыларды бір Wi-Fi желісіне қосыңыз. Қалған құрылғыларда сервер көрсеткен Wi-Fi мекенжайын ашыңыз.
3. Мұғалім экранында демо аты-жөніңіз бен құпиясөзіңізді енгізіңіз. Тақтадан «Тақта» экранын, әр оқушының планшетінен «Оқушы» экранын ашыңыз.
4. 3/4 және 2/3 бөлшектерін жіберіңіз. Оқушы демо атын енгізіп, белгі таңдайды. Мұғалім жеке жауапты, тақта санын көреді.
5. Мұғалім қабылдауды аяқтағанда тақтада жауаптардың аты-жөнсіз бөлінісі көрінеді.

Әр оқушыға бөлек құрылғы немесе бөлек браузер профилі керек. Демо аттарын пайдаланыңыз. Сервер бір сыныпты жүргізеді, мәлімет тек жедел жадта сақталады. Қазақша дыбыстау құрылғыдағы қазақша дауысқа тәуелді. Осы нұсқада жауап таңбамен беріледі.

## Телефон арқылы қосылу

QR-кодпен демоны іске қосу үшін PowerShell-де `.\start-demo.ps1` пәрменін орындаңыз.
Скриптке Python және ReportLab қажет. Codex жинағындағы Python бар болса, скрипт соны қолданады.
Бірнеше желі қосулы болса, Wi-Fi IPv4 мекенжайын `-Address` параметрімен беріңіз.
Тақта экранын ашыңыз. Телефон мен ноутбук бір желіде болуы керек.
Телефон камерасы QR-кодты ашқан соң, оқушы экранға демо атын енгізіп, жауап береді.
Wi-Fi желісі өзгерсе, серверді тоқтатып, скриптті қайта іске қосыңыз.

## Қорғаудағы сценарий

1. Ноутбукте демоны іске қосыңыз және мұғалім экранында тіркеліңіз немесе өз деректеріңізбен кіріңіз.
2. «6-сынып», «Математика», «Жай бөлшектерді салыстыру» тармақтарын таңдаңыз.
3. «Түсіндіруді тақта мен планшетке жіберу» батырмасын басыңыз. «Сынып тақтасын ашу» арқылы бөлек қойынды ашыңыз. Оқушы түсіндіруді ірі мәтінмен, қадамдап немесе тыңдап қарай алады. Ым тілі бөлімі мәтіндік демо ретінде көрсетіледі.
4. Тақтаны проекторға шығарыңыз. Қатысушылар бір Wi-Fi желісінде QR арқылы қосылады.
5. Мұғалім экранынан бірінші сұрақты жіберіңіз. Оқушы телефонынан жауап береді. Жеке жауаптар мұғалімде, жиынтық тақтада көрінеді.
6. Екінші сұрақты жіберсеңіз, қосылып тұрған телефондарда сұрақ автоматты түрде ауысады. Әр сұрақтың жауабын келесі сұрақты жібермей тұрып көрсетіңіз.

## Мұғалім кабинеті

Алғашқы ашылуда демо аты-жөніңізді және кемінде алты таңбалы демо құпиясөзді енгізіп тіркеліңіз. Басқа қойындыдан кіргенде сол деректерді пайдаланыңыз. Бір демо серверінде бір мұғалім тіркеледі. Серверді қайта іске қосқанда демо тіркелгісі өшеді.
